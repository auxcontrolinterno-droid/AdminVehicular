Pasos para corregir el error

Habilitar autenticación anónima

  1. Ve a Firebase Console → Authentication → Sign-in methods
  2. Busca "Anónimo" (Anonymous) en la lista
  3. Haz clic en Editar (lápiz)
  4. Activa el interruptor (debe quedar en azul)
  5. Haz clic en Guardar

Configurar Firestore

  1. Ve a Firestore Database
  2. Si no existe, haz clic en Crear base de datos
  3. Selecciona Iniciar en modo de prueba
  4. En la pestaña Reglas, pega este código:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Probar la conexión

Después de guardar los cambios, espera 30 segundos y recarga esta página (Ctrl+Shift+R).
